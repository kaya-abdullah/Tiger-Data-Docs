## REST API source

The Tiger Cloud API definition is maintained in the [`tiger-cloud-api-docs`](https://github.com/stainless-sdks/tiger-cloud-api-docs) repository. That repository includes the OpenAPI document used to describe the API.

<Callout variant="tip">
  To get started with authentication and your first request, see [Get started with the REST API](/get-started/quickstart/rest-api).
</Callout>

The documentation site builds this page and all other reference sections locally without API credentials.
